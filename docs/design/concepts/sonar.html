What changes from today

  • The list becomes the Descent: one axis, idle time. Awakened sessions cluster at the top and glow; depth (2h, 19h) prints right in mono.
  • No bubbles for the agent. Open prose from the gutter; the tool trace hangs on the same thread line as its turn.
  • The status strip replaces the top bar: environment, what the agent is doing now, who is here, ctx and cost as figures.
  • The command surface keeps the stage's bottom edge: context as a hairline on the edge, the live line above the field, Esc Esc printed there.
  • Panels open as one inspector slab over the stage (Files · Changes · Artifacts · People), never a wall of modals. Sheets on phones stay.
