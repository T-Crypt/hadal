# Concept designs (2026-11-15)

Three full-scale mocks of the HADAL interface, desk (1440) and phone (390) on one page each: **A Sonar**, **B Bell**
(chosen), **C Field**. Static HTML, fonts from a CDN, no app code. They are the decision record for the Bell
default, and the build target for the shell sections of `hadal-ui.md`.
