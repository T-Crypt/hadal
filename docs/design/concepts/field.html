Water and halos

field 0 slab raised signal glow ok warn
  • Type: Schibsted Grotesk for reading (a warmer, wider voice than Geist), Plex Mono for figures. Prose 16px/1.7.
  • Halo = alive. Only the selected session, a running call, the unread light, and the composer wear light. Nothing else glows.

What changes from today

  • The session list becomes a constellation: lights spaced by age, bright ones unread, selected one haloed. Tap a light, the slab changes. Long-press or ⌘K gives the full list sheet.
  • One slab per thing. Conversation, artifact, files: each floats; closing is flick or Esc. The field behind is the marine snow already shipped — it drifts slower while an agent works.
  • One light for everything: the composer and the launcher are the same object — type to ask, ⌘K widens it to commands.
  • The horizon carries only the truth: which environment, what Lantern is doing now.

Honest risks

  • The constellation trades scanning speed for atmosphere; power users will live in the list sheet at first. It earns its keep only if the list sheet is one keystroke away (it is).
  • Floating slabs need real window management (z-order, snap) — the most engineering of the three. Atmosphere already ships the field itself.
  • Schibsted Grotesk is a deliberate break from Geist; it can stay Geist with the same voice, larger.
